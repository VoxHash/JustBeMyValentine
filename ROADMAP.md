# Roadmap — JustBeMyValentine

## Current (v1.0.0)

Shipped: glassmorphism proposal UI, poem page, themes, i18n (8 languages), sounds,
animation presets, photo personalization, local save/export, sender/recipient share links,
and GitHub Pages hosting.

## Near term (v1.1)

- Cloud-backed share links so recipients on another device can load sender settings/photos
- Optional custom message / poem text editor for senders
- Favicon and richer Open Graph / social preview metadata
- Accessibility pass (keyboard focus, reduced-motion preference, ARIA labels)
- Offline-friendly asset bundling option (vendor GSAP/particles/html2canvas locally)

## Mid term (v1.2)

- Additional languages and right-to-left layout support where needed
- More themes and seasonal presets
- Print-optimized export layout
- Lightweight analytics opt-in for demo engagement (privacy-preserving)

## Later (v2.0)

- Optional hosted backend for durable proposals and short links
- QR code card generator for in-person reveals
- Template gallery (proposal styles beyond the default heart scene)
