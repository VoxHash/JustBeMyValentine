# FAQ

## Do I need to install Node or npm?

No. Open the HTML files through a browser or static server.

## Are there environment variables or API keys?

No.

## Can I host this on my own domain?

Yes. Deploy the repository contents to any static host (GitHub Pages, Cloudflare Pages, Netlify, nginx, etc.).

## How many languages are supported?

Eight: English, Spanish, French, German, Italian, Portuguese, Japanese, Chinese.

## Does the runaway "No" button work on mobile?

Hover-based movement is desktop-oriented. On touch devices, the Yes/No buttons remain tappable; behavior may differ without hover.

## Is my photo uploaded to a server?

No. Photos stay in the browser as data URLs in `localStorage` unless you export/share them yourself.
