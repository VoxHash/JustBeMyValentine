# Quick Start

```bash
git clone https://github.com/VoxHash/JustBeMyValentine.git
cd JustBeMyValentine
python3 -m http.server 8080
```

Open http://127.0.0.1:8080/ in your browser.

Or use the live demo: https://voxhash.github.io/JustBeMyValentine/

## 60-second flow

1. Enable audio when prompted.
2. Pick a theme and language.
3. Upload a photo (optional).
4. Click **Yes, I'd love to!** to celebrate and open the poem page.
5. As sender, use **Generate Shareable Link** to create a recipient URL.
