# CLI

There is no application CLI. Use any static file server for local development.

## Python

```bash
python3 -m http.server 8080
```

## Node (optional)

```bash
npx --yes serve -l 8080
```

## PHP (optional)

```bash
php -S 127.0.0.1:8080
```

Open http://127.0.0.1:8080/ after starting a server.
